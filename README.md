# Dog Years Calculator CLI
A Simple C# Program to convert human years to dog years

## How to run
1. Make sure you have the .NET sdk installed
2. Clone the repository 
```
git clone https://github.com/yousif51811/DogAgeCalcCLI
```
3. Run the Program
``` 
Dotnet run
```
4. Enjoy!

## How it works
#### h = Human years
### 1 => Age > 0
```h x 15```
### 1 => Age > 0
```((h - 1) x 9) + 15```
### Age > 2
```((h-2) x 5) + 24```
